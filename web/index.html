Dimensions

The class is the worst dimension, never the average — four hundred photographs that are all out of focus produce an out-of-focus mesh. So there is always exactly one thing worth fixing next.

What this demo is, and is not

It is: the real extractors from lib/metrics.js running on real pixels, scored against the real heritage-v1 rubric — the same code the test suite exercises.

It is not: a capture client. No full-resolution capture, no scale-bar detection, no reconstruction, no provenance binding. Pose comes from device orientation where available and is simulated otherwise, so coverage on a laptop is illustrative rather than real.

A record produced here would be indicative at best. Without a scale reference an object has shape but no size, and an object with no size cannot be measured or matched to an excavation record.
